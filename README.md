# Nehemiah

A co-op game for 2–4 players. You and your friends rebuild the walls of Jerusalem in 52 days (Nehemiah 6:15) — carrying wood, stone and mortar, building the wall, and fighting off the enemies who try to stop you.

## How to play it on your computer (Windows)

You only need to do steps 1–3 once.

1. **Get Godot** (the program the game is made with)
   - Go to https://godotengine.org/download/archive/ and download **Godot 4.7.2** (Windows, "Standard" version — not ".NET").
   - It comes as a `.zip` file. Right-click it → **Extract All**. No installing needed.

2. **Get the game**
   - Go to https://github.com/cnohall/nehemiah
   - Click the green **Code** button → **Download ZIP**.
   - Right-click the downloaded file → **Extract All**.

3. **Open the game in Godot**
   - Open the Godot folder and double-click the file that ends in `.exe` (not the one with "console" in the name).
   - Click **Import**, find the game folder you extracted, and pick the file called `project.godot`.
   - Click **Import & Edit**. The first time it will take a minute or two to load — that's normal.

4. **Play**
   - Press **F5** (or the ▶ play button in the top-right corner).
   - To stop, close the game window.

### Getting the newest version

The game changes often. To get the latest version, repeat step 2 (download the ZIP again) and open that new folder in Godot the same way as step 3.

## Controls

The game shows the controls on screen while you play. It works with keyboard + mouse or a game controller (Xbox-style).

- **Move** around
- **Pick up / deliver / build** — carry materials to the wall, then work on it
- **Drop** what you're carrying
- **Dash**
- **Sling** — hold to charge, let go to throw at enemies
- **Menu** — pause, settings

## Playing together

One person **hosts** the game, the others **join** from the main menu. If you're in the same house, use the local network option. Over the internet, the host shares the lobby code.
